# TlegrammBotTest

Telegram-бот на Node.js для коротких тестов и самоанализа. Интерфейс и вопросы написаны на русском языке.

## Возможности

- главное меню с каталогом тестов, профилем и случайным выбором
- тесты: «Точка опоры», «Стиль общения», «Ресурс и стресс» и «Стиль профессионального поведения»
- прогресс прохождения и цветные шкалы результатов
- профиль с историей пройденных тестов, ответами и кратким выводом
- сброс истории с подтверждением
- тематические изображения на экранах бота

## Методика «Стиль профессионального поведения»

Тест состоит из 10 вопросов с оценочной шкалой от 1 до 5. Он ориентирован на самооценку диапазона между ориентацией на задачи и ориентацией на отношения, а не на пол или личность пользователя.

Психометрические ограничения:

- тест не является стандартизированной методикой и не имеет подтверждённой валидности на русскоязычной выборке;
- пятибалльная шкала ограничивает возможные варианты ответов;
- результаты могут отражать контекст, темперамент и социальное давление, а не только устойчивый профиль;
- минимальное число вопросов не позволяет рассчитывать надежную внутреннюю согласованность;
- обычные ответы не являются диагностическими и не могут использоваться для кадровых решений.

Результат показывает только ориентацию, которая была выбрана в конкретном процессе. Он не определяет пол, компетентность или эффективность человека.

## Требования

- Node.js 18 или новее
- npm

## Установка и запуск

1. Создайте `.env` на основе `.env.example`.
2. Вставьте токен бота в `BOT_TOKEN`.
3. Установите зависимости и запустите бота:

```bash
npm ci
npm start
```

Чтобы ограничить доступ, укажите разрешённые идентификаторы чатов в `ALLOWED_CHAT_IDS`, разделяя их запятыми. Пустое значение разрешает доступ всем пользователям.

## Команды

- `/start` — открыть главное меню
- `/help` — справка и контакт поддержки
- `/reset` — прервать текущий тест, не удаляя историю профиля

Историю завершённых тестов можно удалить из профиля: бот попросит подтвердить сброс.

## Данные и конфиденциальность

- бот не спрашивает имя, телефон, электронную почту или другие личные сведения
- ответы и история привязаны к идентификатору чата и хранятся только в оперативной памяти
- перезапуск бота удаляет все профили и ответы; база данных не используется
- токен хранится в локальном `.env`, который исключён из Git

Подробности приведены в [политике безопасности](SECURITY.md).
