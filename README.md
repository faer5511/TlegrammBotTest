# TlegrammBotTest

Простой Telegram-бот на Node.js для анкетирования и самоанализа. Проект создан как базовый шаблон: вопросы, логика, анонимность и готовая структура для дальнейших правок.

## Что умеет бот

- приветствие пользователя
- запуск короткой анкеты
- пошаговый опрос по вопросам
- хранение данных только в временной сессии
- базовая защита персональных данных

## Стек

- Node.js
- JavaScript
- node-telegram-bot-api
- dotenv

## Быстрый запуск

1. Создайте файл `.env` по образцу `.env.example`
2. Укажите токен Telegram-бота:

```env
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
```

3. Установите зависимости:

```bash
npm install
```

4. Запустите бота:

```bash
npm start
```

## Команды бота

- `/start` — начать анкетирование
- `/help` — справка
- `/reset` — сбросить текущую сессию

## Защита данных

- бот не запрашивает имя, номер телефона, email, паспортные данные и прочую персональную информацию
- данные хранятся только в памяти во время текущей сессии
- секреты хранятся в локальном `.env`, который не попадает в Git
